# Expense Tracker

A Next.js expense tracking app with budgets, expenses, loans, groups, splits, authentication, Prisma, and PWA support.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run start
```

## Cross-Platform Apps

This repo is already set up as an installable PWA for Windows, macOS, Linux, Android, iPhone, and iPad when deployed over HTTPS.

See [CROSS_PLATFORM.md](./CROSS_PLATFORM.md) for the release plan and native wrapper options.
